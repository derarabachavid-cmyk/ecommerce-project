# 🛍️ E-Commerce Web Application

A modern full-stack e-commerce web application built with Django.

## 🚀 Features

- Modern responsive homepage
- Product catalog
- Product categories
- Product search
- Product details
- Shopping cart
- Add, update and remove cart items
- User registration
- User login/logout
- Secure checkout
- Order creation
- Order history
- Order details
- Product stock management
- Django Admin dashboard
- Responsive mobile design
- Professional UI

## 🛠️ Technologies

### Backend
- Python
- Django
- SQLite

### Frontend
- HTML5
- CSS3
- JavaScript
- Django Templates

### Tools
- Git
- GitHub
- VS Code
